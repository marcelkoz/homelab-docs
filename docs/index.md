# Homelab

Welcome to the Homelab documentation site!

:::

## Overview

This site documents how my homelab is built and run: the network layer, covering the IP addressing, VLANs, network devices and services like DNS; the Proxmox hosts and the virtual machines on them; and the services that sit on top, including backups and internal DNS. It is working documentation rather than a polished guide, so pages describe the setup as it actually runs and change as the lab changes.
